Difference between <ol> and <ul> Tags

The <ol> and <ul> tags are used to create lists in HTML. <ol> creates a numbered (ordered) list, while <ul> creates a bulleted (unordered) list.

Feature <ol> <ul>
Type Ordered (numbered) Unordered (bulleted)
Order Importance Important Not Important

Example of <ol>:

<ol>
  <li>Step 1</li>
  <li>Step 2</li>
  <li>Step 3</li>
</ol>
  1. Step 1
  2. Step 2
  3. Step 3

Example of <ul>:

<ul>
  <li>HTML</li>
  <li>CSS</li>
  <li>JavaScript</li>
</ul>
  • HTML
  • CSS
  • JavaScript
