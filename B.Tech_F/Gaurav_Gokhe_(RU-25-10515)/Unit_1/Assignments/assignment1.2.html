Purpose of the <a> Tag in HTML

Explanation:

The <a> tag, also known as the anchor tag, is used to create hyperlinks in a web page. It allows users to navigate from one page or website to another by clicking on the link text.

Syntax:

<a href="URL" target="value">Link Text</a>

Explanation of Each Part:

  • <a> → Defines the start of a hyperlink.
  • href="URL" → Specifies the destination link.
  • target="value" → Decides where to open the link (e.g., new tab).
  • Link Text → The clickable text users see.
  • </a> → Closes the anchor tag.

Example:

<a href="https://www.wikipedia.org" target="_blank">Visit Wikipedia</a>

Output:

👉 Visit Wikipedia
