HTML Attributes

Introduction

HTML attributes provide additional information about elements. They appear inside the opening tag as name="value" and help control behavior, appearance, and accessibility.

Syntax

<element attribute="value">Content</element>

Common Attributes

  • href – defines the link URL (used in <a> tag)
  • src – defines the image source (used in <img> tag)
  • alt – alternative text for images
  • id – unique identifier
  • class – CSS class for styling

Example: Link

<a href="https://www.example.com" target="_blank">Visit Example</a>

Output: Visit Example
