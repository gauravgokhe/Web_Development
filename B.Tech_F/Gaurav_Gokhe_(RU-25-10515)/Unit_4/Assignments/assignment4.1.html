Array Methods in JavaScript

Arrays in JavaScript are used to store multiple values in a single variable. JavaScript provides built-in methods to add or remove elements from an array. The methods push(), pop(), shift(), and unshift() are commonly used for this purpose.

Method Operation Position Affected
push() Adds an element End of array
pop() Removes an element End of array
unshift() Adds an element Beginning of array
shift() Removes an element Beginning of array
