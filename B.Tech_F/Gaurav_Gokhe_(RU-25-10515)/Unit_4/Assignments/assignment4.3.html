Event Delegation and addEventListener

In JavaScript, events such as clicks, key presses, or mouse movements are handled using event listeners. The method addEventListener() is used to attach an event handler to an element. Event Delegation is a technique where a single event listener is added to a parent element instead of multiple child elements.

Concept Description
addEventListener() Attaches an event handler to an element without overwriting existing events
Event Delegation Handling events at the parent level using event bubbling
event.target Identifies the actual element that triggered the event
