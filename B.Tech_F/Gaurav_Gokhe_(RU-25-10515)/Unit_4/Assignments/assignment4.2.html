Promises and Async/Await in JavaScript

JavaScript is asynchronous in nature, which means some operations like fetching data or waiting for a response take time. Promises and async/await are used to handle such asynchronous operations in an easy and readable way.

Concept Description
Promise An object that represents the future result of an asynchronous operation
Resolved Promise completed successfully
Rejected Promise failed with an error
async/await Simpler syntax to handle promises like synchronous code
