Inline CSS Example

Inline CSS is written directly inside an HTML tag using the style attribute.

Internal CSS Example

This paragraph uses Internal CSS defined inside the <style> tag within the <head> section.

Internal CSS is useful when styling a single web page.

External CSS Example

External CSS is written in a separate .css file and linked to the HTML document using the <link> tag.

It is used to apply the same style to multiple web pages and keeps HTML clean.
