Document Object Model (DOM)

The Document Object Model (DOM) is a programming interface that represents an HTML document as a tree of objects. JavaScript uses the DOM to access, change, add, or remove elements and content from a webpage dynamically.

Selecting Elements in DOM

Method Description Example
getElementById() Selects an element using its ID document.getElementById("demo")
querySelector() Selects the first matching element document.querySelector(".box")

innerText vs innerHTML

Feature innerText innerHTML
Content Type Text only Text + HTML tags
HTML Parsing Does not parse HTML Parses HTML tags
