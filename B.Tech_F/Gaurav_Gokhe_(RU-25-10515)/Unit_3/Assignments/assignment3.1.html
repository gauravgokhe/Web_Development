Difference between var, let, and const

In JavaScript, var, let, and const are used to declare variables. They differ mainly in terms of scope, hoisting, and reassignment.

Feature var let const
Scope Function Scope Block Scope Block Scope
Hoisting Hoisted and initialized Hoisted but not initialized Hoisted but not initialized
Use before declaration Allowed (undefined) Not allowed Not allowed
Redeclaration Allowed Not allowed Not allowed
Reassignment Allowed Allowed Not allowed
