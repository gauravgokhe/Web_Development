Function of the <img> Tag

Explanation:

The <img> tag is used to display images on a web page. It is an empty tag and does not have a closing tag. Images improve the appearance and communication of web content.

Syntax:

<img src="imagepath" alt="description">

Common Attributes:

  • src → Specifies the path or URL of the image file.
  • alt → Displays alternative text if the image is not found.
  • width and height → Define the size of the image (optional).

Example:

<img src="nature.jpg" alt="Beautiful Nature" width="300" height="200">
